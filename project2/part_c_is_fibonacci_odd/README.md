## How to run
1. Open MARS and choose File > Open, then select is_fibonacci_odd.asm
2. Press F3 to assemble, then F5 to run
3. In the Data Segment panel, the input is the first word (address 0x10010000)
   and the result is the second word (address 0x10010004)
4. To test another input, change the value of the input label in .data, then re-assemble
